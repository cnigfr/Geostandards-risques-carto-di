# Scripts

Le script [20261020_REQ_convTriCovadis2Cnig.sql](./20261020_REQ_convTriCovadis2Cnig.sql) est un script expérimental réalisé par [StanBesson](https://github.com/StanBesson) permettant de convertir un TRI (celui de Vienne) du format COVADIS au présent standard (dans sa version 0.1). Le TRI résultant est consultable [ici](../jeux-tests/Carto-DI-v0.1/FRD_TRI_VIENNE.gpkg).

Il est présenté ici à titre informatif. Il ne s'agit pas d'un outil directement réutilisable pour la production des données de cartographies de la directive inondation.
